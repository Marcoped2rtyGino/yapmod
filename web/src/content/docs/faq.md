### Is yapmod official?

No. It’s an unofficial, community-made client and isn’t affiliated with Yapper.

### Do I need a Yapper account?

Yes. yapmod is a client for Yapper, so you sign in with your Yapper account.

### Is it free?

Yes. yapmod is open source and the code is public.

### Which version should I use?

The latest release. The project is early, and older builds won’t get fixes.

### Where can I talk to people?

Join the official Yapper server: [yapper.website/invite/develop](https://yapper.website/invite/develop).
