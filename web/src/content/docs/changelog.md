A short summary of every release, newest first. The same list is available inside the app, under **Settings → Changelog**.

## Unreleased

- Nothing yet.

## 0.3.0 — Notifications, voice calls and updates

- Unread and mention badges, desktop notifications and notification sounds on Windows, macOS and Linux.
- Voice calls now work on macOS, with the microphone permission handled by the app.
- Added an update check, an update notice, and a setting to turn the automatic check off.
- Added a changelog section to the settings page.
- Added this documentation site, with full-text search.
- Your settings from older versions are migrated correctly across updates.
- Fixed the previous settings panel staying visible when switching sections, and the Linux app icon.

## 0.2.0 — Settings, links and a website

- Added a yapmod section to Yapper's settings, so desktop options live next to the rest of the app.
- Added an official landing page with direct downloads for Windows, macOS and Linux.
- External links now open in your default browser instead of inside the app.

## 0.1.2 — A smoother first launch

- macOS builds are ad-hoc signed, so the app opens without a damaged app warning.
- The login screen opens when you are not signed in.
- Release notes appear after an update, and the version you last ran is remembered.

## 0.1.1 — Modals and configuration

- Added a welcome screen on the first launch.
- Added a config file with options for the native titlebar and starting maximized.

## 0.1.0 — The first release

- Yapper now runs in its own desktop window, with the custom macOS titlebar and yapmod's icons.
