1. For anything larger than a small fix, [open an issue](https://github.com/ilyeshdz/yapmod/issues) first. The project is early, so it’s worth agreeing on direction.
2. Fork the repository and set it up with [Run from source](run-from-source).
3. Keep your pull request focused and consistent with the existing code.
4. Run the checks from [CI and releases](ci-and-releases) before you push.

## Commit messages

The history uses conventional prefixes such as `feat`, `fix`, `refactor`, `style`, `chore` and `ci`, often with a scope.

```text
fix(injection): hide the previous settings panel when switching sections
```

## Community

Ask questions on the official Yapper server: [yapper.website/invite/develop](https://yapper.website/invite/develop).
