It wraps Yapper in its own native window built with Tauri, and adds yapmod's own interface on top. It is a community project and is not made by or affiliated with Yapper.

> **Early development**
> yapmod is young. Expect missing features, rough edges and breaking changes.

## At a glance

- **Open source:** the whole client is public on GitHub.
- **Desktop app:** a Tauri shell with a TypeScript front end, bundled with Vite.
- **Cross-platform:** Windows, macOS (Intel and Apple Silicon) and Linux builds.
- **Current version:** 0.3.0 in `package.json`.
