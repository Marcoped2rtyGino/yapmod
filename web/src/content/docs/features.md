yapmod is meant to disappear into the background. You open it, it looks like Yapper, and it quietly does the things a browser tab cannot. This page is the overview; the details live on the pages it links to.

## A window that behaves like an app

Yapper runs in its own native window with the yapmod name and icon. It has a real titlebar, remembers its size, and can start maximized if you prefer. On macOS you can keep the standard titlebar or use the compact overlay style.

## Integration with your desktop

This is where yapmod earns its place as a desktop app rather than a website in a window. Unread and mention indicators, desktop notifications, sounds and application badges keep you informed while yapmod sits in the background. [Desktop integration](desktop-integration) explains each one and which platforms support it.

## Voice calls that just work

Joining a call uses your microphone through the desktop app, including the macOS permission prompt the first time. Permissions are granted only to Yapper itself, never to a page yapmod has navigated away to.

## Links that open where they should

Following a link to another site opens it in your default browser. Nothing gets trapped in a window that cannot show it.

## Settings that stay with you

yapmod adds its own section to Yapper's settings, holding the options that affect the desktop client — starting maximized, the macOS titlebar style, automatic update checks, and more. Settings are saved as you change them and survive updates.

## Releases you can follow

The same settings area includes a changelog, so you can read the notes for every release without leaving the app. When a new version is out, yapmod tells you and links you to the download.

## Making it yours

yapmod has a theme system of its own. A theme is a folder with a manifest and a stylesheet, you install it yourself, and it is applied to the whole app — the chat, the settings, the dialogs. [Themes](themes) explains how to use one, and [Creating a theme](creating-themes) how to write one.

## Still missing something?

yapmod is early, and the roadmap is open. [Open an issue](https://github.com/ilyeshdz/yapmod/issues) and describe what you would like and why.
