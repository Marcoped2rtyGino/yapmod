> This list follows the repository’s recent commits. The project moves fast, so check the [changelog](changelog) for the newest additions.

| Feature | Details |
| --- | --- |
| Native desktop window | Yapper in its own app window with its own installer, built on Tauri. |
| Login handling | Opens the Yapper login screen when you aren’t signed in. |
| External links | Opened in your default browser. |
| Settings panel | yapmod’s own settings, split into sections. |
| Update check | A real update check with an update notice modal. |
| Injection layer | yapmod’s additions are written as TypeScript modules and bundled into the app. See [Project structure](project-structure). |

## Requesting a feature

Open an [issue](https://github.com/ilyeshdz/yapmod/issues) and describe what you’d like and why.
